# Roadmap

## Phase 1: Foundation

Create the package structure, CLI skeleton, documentation, tests, and CI.

## Phase 2: Audit Models and Issue Schema

Define typed audit results, issue IDs, severities, scoring inputs, and stable
serialization contracts.

## Phase 3: Deterministic Checks and Scoring

Implement core dataset checks and readiness scoring for tabular ML datasets.

## Phase 4: Reports

Generate human-readable and machine-readable reports from deterministic audit
results.

## Phase 5: Contracts and Validation

Create dataset contracts and deterministic validation workflows.

## Phase 6: AI Review Engine and LangGraph Workflow

Add AI explanations, prioritization, provider abstractions, and LangGraph
workflow orchestration around deterministic findings.

## Phase 7: Public Release Polish

Harden docs, examples, packaging metadata, error handling, and release process.
