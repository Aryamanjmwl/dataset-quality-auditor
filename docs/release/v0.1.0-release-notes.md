# Dataset Quality Auditor v0.1.0 Release Notes

Draft release notes for the first public GitHub release.

## Summary

Dataset Quality Auditor v0.1.0 is an early-stage, CLI-first deterministic
dataset readiness auditor for tabular machine learning datasets. It currently
supports local CSV files and focuses on reproducible audit findings before
model training.

## Highlights

- Deterministic audit engine with structured issue evidence.
- Readiness scoring for dataset training risk.
- Single-dataset and train/test audit modes.
- JSON, Markdown, and self-contained HTML reports.
- YAML data contract generation and deterministic validation.
- Guarded mock AI review that references existing audit issue IDs.
- Local graph-style review workflow for prioritization, safe next steps,
  contract advice, and Markdown review output.
- Public example datasets and curated sample artifacts under `examples/`.

## CLI Workflow

```bash
dqa audit examples/datasets/classification_dirty.csv --target label --format all
dqa audit examples/datasets/train_sample.csv --test examples/datasets/test_sample.csv --target label --format all
dqa report reports/audit.json --format html
dqa contract examples/datasets/classification_dirty.csv --target label
dqa validate examples/datasets/classification_dirty.csv --contract contracts/classification_dirty_contract.yaml
dqa review reports/audit.json --provider mock --workflow graph
```

## Release Checks

- Tests run with pytest.
- Coverage is reported locally and in CI.
- Linting runs with ruff.
- Package artifacts build with `python -m build`.
- Package artifacts pass `python -m twine check dist/*`.
- GitHub Actions runs on Python 3.10, 3.11, and 3.12.
- Dependency audit automation is present and initially non-blocking.

## Safety Model

- The deterministic audit engine is the source of truth.
- Reports display deterministic findings and metadata.
- Mock AI review is constrained to existing deterministic findings.
- AI review cannot change readiness scores or score bands.
- AI review cannot modify datasets.
- Mock AI review must reference deterministic issue IDs.

## Known Limitations

- Input support is limited to local CSV files.
- The AI provider is mock/local only; no external provider is included.
- Contracts are inferred from observed data and need human review.
- Leakage findings are deterministic candidates, not proof of leakage.
- The tool does not clean, rewrite, or mutate datasets.
- This project is not a replacement for full validation platforms such as
  Great Expectations, Pandera, or Evidently.

## Next Steps

- Keep the v0.1.x line focused on stability, documentation, and deterministic checks.
- Tag the release as `v0.1.0`.
- Keep future provider adapters and broader data source support out of the
  v0.1.0 release branch.
