# Dataset Quality Auditor v0.2.0 Release Notes

Release notes for the post-v0.1.0 feature release.

## Summary

Dataset Quality Auditor v0.2.0 builds on the initial public release with more
deterministic train/test readiness checks, optional audit threshold
configuration, compact audit summaries, and CI-friendly gate evaluation.

The project remains local-install/source-release oriented unless a PyPI package
is published separately. Install from the repository with:

```bash
python -m pip install -e ".[dev]"
```

## Highlights

- Added deterministic train/test drift checks for schema, numeric,
  categorical, and target distribution changes.
- Added optional audit threshold configuration with `dqa audit --config`.
- Added `examples/audit-config.yaml` with safe default threshold values.
- Added `dqa summary` for compact text or JSON summaries of existing
  `audit.json` files.
- Added `dqa gate` for CI/CD quality gates based on existing audit JSON.
- Added concise CI gate documentation.
- Polished CLI help text for current local CSV workflows.
- Added regression coverage for generated output artifacts.

## Example Workflow

```bash
dqa audit examples/datasets/train_sample.csv --test examples/datasets/test_sample.csv --target label --format all
dqa summary reports/audit.json --format json
dqa gate reports/audit.json --min-score 80 --max-critical 0 --max-high 0
```

Optional threshold configuration:

```bash
dqa audit examples/datasets/train_sample.csv --test examples/datasets/test_sample.csv --target label --config examples/audit-config.yaml
```

## Compatibility Notes

- No audit JSON schema breaking changes are expected in this release.
- Train/test audits may emit new deterministic drift findings.
- Readiness scores may decrease when the new checks detect additional issues.
- Configurable thresholds are optional.
- Default threshold values preserve existing behavior unless a config file is
  provided.
- Internal component/schema versions such as `engine_version`,
  `contract_version`, and `review_version` may remain at `0.1.0`; they are not
  package release version identifiers.

## Safety Model

- The deterministic audit engine remains the source of truth.
- `dqa summary` and `dqa gate` read existing audit JSON and do not rerun audits.
- `dqa gate` does not modify audit files or datasets.
- Drift findings are deterministic readiness signals, not statistical
  significance claims.

## Known Limitations

- Input support remains focused on local CSV files.
- The AI provider remains mock/local only.
- No Docker image, publishing workflow, dashboard, or cloud connector is
  included.
- Configurable thresholds currently cover supported audit thresholds only.
